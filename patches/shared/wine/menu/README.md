# Menu compatibility

Unconditional Wine source patch that sets the application menu Quit item to the standard Command-Q key equivalent. It applies in the `combined` stage only. It has no `ARKNIGHTS_RUNTIME_` gate. See the [Menu patch registry](../../../docs/patch-registry.md#menu).

Apply: `0001-winemac-command-q-quit.patch` to the pinned WineCX source.
