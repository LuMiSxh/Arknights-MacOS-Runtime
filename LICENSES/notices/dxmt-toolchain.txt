Which runtime pieces are linked is inferred from the -static link flag. It is not verified in the binaries.
This project did not inspect the DXMT DLLs. The DLLs may contain more or fewer of these pieces.

Evidence:
- build-win64.txt of DXMT selects x86_64-w64-mingw32-gcc and x86_64-w64-mingw32-g++.
  The CI workflows install them with "brew install mingw-w64". The formula version is not pinned.
- meson.build of DXMT adds -static to the link arguments. With GCC this links libstdc++,
  libgcc, and the mingw-w64 runtime into d3d10core.dll, d3d11.dll, dxgi.dll, and winemetal.dll.
- The toolchain on the machine of the maintainer is Homebrew mingw-w64 14.0.0 with GCC 16.2.0,
  binutils 2.47, and the posix thread model. The compiler and the other build tools are not shipped.
